  Problem: "Backend build failed"
  Solution:
    1. Go to Railway dashboard
    2. Click backend service
    3. Click "Logs" tab
    4. Look for error message
    5. Usually: missing file → ensure all files pushed to GitHub
    6. Click "Deploy" to retry

  Problem: "Frontend won't load"
  Solution:
    1. Check REACT_APP_API_URL is set correctly
    2. Ensure backend URL ends with /api/v1
    3. Click "Deploy" to restart frontend
    4. Wait 3 minutes and try again

  Problem: "Database connection error"
  Solution:
    1. Ensure PostgreSQL service is running
    2. Check Railway connected DATABASE_URL automatically
    3. Restart backend service
    4. Wait 2 minutes and try again
